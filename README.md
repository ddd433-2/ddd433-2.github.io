# ddd433-2.github.io

Personal site published with **GitHub Pages** (free tier).

- Source of truth: `index.html` at the repo root
- Publishing source: `main` branch, root folder
- Deploy: GitHub Actions runs the Pages build automatically on every push to `main`

To change the site, edit `index.html` and push. Changes go live in about a minute.

## Notes

- Pages sites are always public on the internet, even from a private repo.
- `index.html`, `index.md`, or `README.md` at the source root acts as the entry point.
- Static files only — no PHP, Ruby, or Python on Pages. For a framework, use a custom build workflow.
